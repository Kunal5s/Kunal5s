This is the root directory for the project. It contains the backend, frontend, and shared components.

## Backend

The backend is responsible for handling incoming requests and returning responses. It is organized into the following subdirectories:

* `controllers`: Contains the controllers for the backend. Controllers are responsible for handling incoming requests and returning responses.
* `models`: Contains the models for the backend. Models are responsible for representing the data in the application.
* `services`: Contains the services for the backend. Services are responsible for implementing the business logic of the application.
* `utils`: Contains utility functions for the backend. Utility functions are small, reusable functions that can be used throughout the backend.

## Frontend

The frontend is responsible for rendering the user interface and interacting with the user. It is organized into the following subdirectories:

* `components`: Contains the components for the frontend. Components are reusable UI elements that can be used to build pages.
* `pages`: Contains the pages for the frontend. Pages are the top-level UI elements that represent different views in the application.
* `assets`: Contains the assets for the frontend. Assets are static files such as images, fonts, and stylesheets.

## Shared

The shared directory contains any code or resources that are shared between the backend and frontend. This can include things like data validation logic, and data transfer objects (DTOs).
